type TCefKeyboardInputEvent = record

Description

Portable keyboard snapshot. Identity and text are resolved by the sender; sending does not look up the receiving keyboard layout. DOM code/key use Chromium's USB-based DomCode and encoded DomKey values, respectively.

Description

Fields

Public size: NativeUInt;

Size of this structure. Initialize to sizeof(TCefKeyboardInputEvent).

Public type_: TCefKeyEventType;

Keyboard event type. See the CEF_KEY_EVENT_* constants.

Public modifiers: TCefEventFlags;

Combination of TCefEventFlags CEF_EVENTFLAG_* values for Shift, Control, Alt, Command, AltGr, Caps Lock, Num Lock, keypad/left/right location, repeat, and held left/middle/right mouse buttons. CEF_EVENTFLAG_PRECISION_SCROLLING_DELTA and CEF_EVENTFLAG_SCROLL_BY_PAGE are not valid keyboard modifiers. Other flags outside this keyboard subset are also invalid when sending.

Public timestamp: int64;

Monotonic microseconds in this process. Zero means use the send time. Negative values are invalid. This is a process-local monotonic timestamp, not a wall-clock time.

Public dom_code: cardinal;

Physical key identity in Chromium's USB-based DomCode encoding. Use CEF_DOM_CODE_* values, or zero if unknown. Identifies the key's physical position independently of the active keyboard layout.

Public dom_key: cardinal;

Logical key meaning in Chromium's encoded DomKey representation. Use CEF_DOM_KEY_* named values, or encoded Unicode/dead-key values as defined by cef_dom_key_t. Zero indicates no known logical key value.

Public windows_key_code: integer;

Windows-equivalent virtual-key code used by Chromium on every platform, or zero if unknown. Modifier-key location is conveyed by |modifiers|. CefWindowsKeyCodeFromDomCodeAndKey can derive this value from portable key identity.

Public is_system_key: integer;

Set to 1 for Chromium's system-key classification, or 0 otherwise. Native Windows conversion preserves the distinction between ordinary and system key messages; other platforms normally use zero.

Public text: array[0..3] of WideChar;

Text generated by this event. Blink-compatible UTF-16 buffers. Each buffer must contain a zero terminator within its four units, allowing at most three units of text. Preserve all four units, including any after the terminator. Windows CHAR messages may each contain one surrogate unit; conversion does not buffer across messages. Text in RAWKEYDOWN is metadata; character insertion requires a separate CHAR event.

Public unmodified_text: array[0..3] of WideChar;

Text with modifiers other than Shift removed, following Blink's native conversion semantics. Preserve this source buffer when replacing |text| with insertion text; do not copy modified insertion text into this field. Uses the same UTF-16 buffer format and termination requirements as |text|.
