type TCefGestureInputEvent = record

Description

Portable gesture snapshot. Only the fields documented for |type| apply; initialize other subtype fields to zero. Positions are widget/screen DIPs. Exposed values retain their Blink representation and semantics. Event names in member descriptions refer to CEF_GESTURE_EVENT_* values. All floating-point members must be finite. Boolean members accept 0 or 1.

Description

Fields

Public size: NativeUInt;

Size of this structure. Initialize to sizeof(TCefGestureInputEvent).

Public type_: TCefGestureInputEventType;

Gesture event type. See the CEF_GESTURE_EVENT_* constants. Determines which subtype-specific members apply.

Public modifiers: TCefEventFlags;

Combination of TCefEventFlags CEF_EVENTFLAG_* values for keyboard modifiers, lock state, held mouse buttons, and event-source attributes. Precision-scrolling and scroll-by-page flags are not valid for gesture input; specify scrolling units with |delta_units|.

Public timestamp: int64;

Monotonic microseconds in this process. Zero means use the send time. Negative values are invalid. This is a process-local monotonic timestamp, not a wall-clock time.

Public x: single;

Horizontal position in DIPs. When sending, relative to the left edge of the browser view; in callbacks, relative to the receiving widget after input routing.

Public y: single;

Vertical position in DIPs. When sending, relative to the top edge of the browser view; in callbacks, relative to the receiving widget after input routing.

Public screen_x: single;

Horizontal screen position in DIPs, relative to the desktop origin.

Public screen_y: single;

Vertical screen position in DIPs, relative to the desktop origin.

Public source_device: TCefGestureDevice;

Device or scrolling source that generated the gesture. Sending requires an initialized source, such as CEF_GESTURE_DEVICE_TOUCHPAD or CEF_GESTURE_DEVICE_TOUCHSCREEN.

Public primary_pointer_type: TCefPointerType;

Device classification of the first touch point in the gesture sequence. Use CEF_POINTER_TYPE_UNKNOWN when the initiating pointer type is unavailable.

Public primary_unique_touch_event_id: cardinal;

Correlation ID of the first touch event in the gesture sequence. Identifies the initiating touch event independently of |unique_touch_event_id|. Use zero when there is no associated touch event.

Public unique_touch_event_id: cardinal;

For touchscreen gestures, correlation ID of the touch event that released this gesture from Chromium's touch-disposition filter. Zero is used when the gesture was not released through a touch event, including synthesized gestures, pinches, and gestures from other source devices.

Public is_source_touch_event_set_blocking: integer;

Set to 1 if the source touch event was marked to block subsequent input, or 0 otherwise. Describes source touch dispatch policy independently of whether the gesture is consumed.

Public tap_count: integer;

Tap count for TAP, TAP_UNCONFIRMED, and DOUBLE_TAP, or tap-down count for TAP_DOWN. Must be nonnegative. Set to zero for other event types.

Public width: single;

Nonnegative horizontal extent of the contact area in DIPs. Applies to TAP, TAP_UNCONFIRMED, DOUBLE_TAP, TAP_DOWN, SHOW_PRESS, SHORT_PRESS, LONG_PRESS, and LONG_TAP. For TWO_FINGER_TAP, describes the first finger's contact area. Set to zero for other event types.

Public height: single;

Nonnegative vertical extent of the contact area in DIPs. The event types and contact selection are the same as for |width|.

Public delta_x: single;

Horizontal scroll amount in |delta_units|. For SCROLL_BEGIN, the initial movement hint; for SCROLL_UPDATE, the scroll delta; for SCROLL_END, the latency-compensated delta not already sent as updates. Positive values scroll left. Set to zero for other event types.

Public delta_y: single;

Vertical scroll amount in |delta_units|, with the same subtype meanings as |delta_x|. Positive values scroll up. Set to zero for other event types.

Public delta_x_unconstrained: single;

Horizontal SCROLL_UPDATE delta before axis locking or snapping, in |delta_units| and with the same sign convention as |delta_x|. Set to zero for other event types.

Public delta_y_unconstrained: single;

Vertical SCROLL_UPDATE delta before axis locking or snapping, in |delta_units| and with the same sign convention as |delta_y|. Set to zero for other event types.

Public delta_units: TCefGestureScrollUnits;

Granularity of scroll hints or deltas for SCROLL_BEGIN, SCROLL_UPDATE, and SCROLL_END, including unconstrained update deltas. Zero selects CEF_GESTURE_SCROLL_PRECISE_PIXEL. Set to zero for other event types.

Public inertial_phase: integer;

Momentum phase for SCROLL_BEGIN, SCROLL_UPDATE, and SCROLL_END: 0 unknown, 1 non-momentum, 2 momentum. Touchscreen scrolling uses zero and represents flinging with FLING_START. Set to zero for other event types.

Public pointer_count: integer;

Number of pointers down at SCROLL_BEGIN. Must be nonnegative. Set to zero for other event types.

Public scale: single;

Relative scale factor for PINCH_UPDATE. Must be positive: 1 leaves the scale unchanged, values greater than 1 zoom in, and values less than 1 zoom out. Set to zero for other event types.

Public velocity_x: single;

Initial horizontal fling velocity in pixels per second for FLING_START. Set to zero for other event types.

Public velocity_y: single;

Initial vertical fling velocity in pixels per second for FLING_START. Set to zero for other event types.

Public target_viewport: integer;

Set to 1 to target the viewport, or 0 to use normal gesture targeting. Applies to SCROLL_BEGIN, FLING_START, and FLING_CANCEL. Scroll-begin and fling-start viewport targeting skip the normal hit test. Set to zero for other event types.

Public prevent_boosting: integer;

For FLING_CANCEL, set to 1 to exclude this cancellation from fling boosting, or 0 for normal processing. Fling boosting combines successive flings into a continuation. Set to zero for other event types.

Public needs_wheel_event: integer;

For touchpad PINCH_BEGIN, PINCH_UPDATE, PINCH_END, and DOUBLE_TAP, set to 1 to offer the gesture as a wheel event first, or 0 to dispatch the gesture directly. Chromium may clear this flag and resubmit the gesture after the wheel acknowledgment. Set to zero for other devices and event types.

Public zoom_disabled: integer;

For touchpad PINCH_UPDATE, set to 1 to prevent page-scale changes while preserving wheel handling requested by |needs_wheel_event|, or 0 for normal zooming. Set to zero for other devices and event types.

Public synthetic: integer;

For SCROLL_BEGIN, set to 1 when generated from a mouse wheel or scrollbar. For SCROLL_END, set to 1 when generated from a wheel event with a synthetic phase. Use zero otherwise.

Public cursor_control: integer;

For SCROLL_BEGIN, set to 1 to use the entire scroll sequence for cursor control instead of scrolling, or 0 for normal scrolling. Set to zero for other event types.
