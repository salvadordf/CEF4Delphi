Description

Portable mouse snapshot. Positions are floating point DIPs relative to the target widget and screen, respectively. Values retain Blink semantics. Event names in member descriptions refer to CEF_MOUSE_EVENT_* values.

Description

Fields

Public size: NativeUInt;

Size of this structure. Initialize to sizeof(TCefMouseInputEvent).

Public type_: TCefMouseInputEventType;

Mouse event type. See the CEF_MOUSE_EVENT_* constants.

Public modifiers: TCefEventFlags;

Combination of TCefEventFlags CEF_EVENTFLAG_* values for keyboard modifiers, lock state, held mouse buttons, and event-source attributes. Held-button flags describe the state after a down/up transition; |button| identifies the button that changed. Precision-scrolling and scroll-by-page flags are not valid for mouse input.

Public timestamp: int64;

Monotonic microseconds in this process. Zero means use the send time. Negative values are invalid. This is a process-local monotonic timestamp, not a wall-clock time.

Public x: single;

Horizontal position in DIPs. When sending, relative to the left edge of the browser view; in callbacks, relative to the receiving widget after input routing.

Public y: single;

Vertical position in DIPs. When sending, relative to the top edge of the browser view; in callbacks, relative to the receiving widget after input routing.

Public screen_x: single;

Horizontal screen position in DIPs, relative to the desktop origin.

Public screen_y: single;

Vertical screen position in DIPs, relative to the desktop origin.

Public button: TCefMouseButtonType;

Changed button for DOWN/UP events, or a held button for movement events. Use CEF_MOUSE_BUTTON_NONE when no button applies. If several buttons are held, this field identifies one of them; |modifiers| contains the complete held-button state.

Public click_count: integer;

Number of consecutive clicks associated with the event: 1 for a single click, 2 for a double click, and so on. Must be nonnegative. Use zero for events without a click count.

Public pointer_type: TCefPointerType;

Device classification of the pointer, such as CEF_POINTER_TYPE_MOUSE or CEF_POINTER_TYPE_PEN. Use CEF_POINTER_TYPE_UNKNOWN when unavailable.

Public pointer_id: integer;

Identifier of the pointer that produced the event. Preserve it for related events from the same pointer. Blink uses INT32_MAX for the ordinary mouse pointer.

Public pressure: single;

Normalized contact pressure in [0,1], or NaN if unsupported by the device. Zero represents no pressure and one represents maximum pressure.

Public tilt_x: double;

Stylus tilt from the surface normal in the X-Z plane, in degrees in [-90,90]. Positive values tilt to the right. Use zero when unsupported.

Public tilt_y: double;

Stylus tilt from the surface normal in the Y-Z plane, in degrees in [-90,90]. Positive values tilt towards the user. Use zero when unsupported.

Public tangential_pressure: single;

Normalized barrel pressure in [-1,1]. Zero is the neutral position and is also used when the device does not support this attribute.

Public twist: integer;

Clockwise stylus rotation around its major axis, in degrees in [0,359]. Use zero when unsupported.

Public movement_x: integer;

Horizontal movement reported by the input source, preserved without conversion. Raw OS movement uses device units when |is_raw_movement_event| is 1. With that flag set to 0, Blink may derive DOM movement from position changes instead.

Public movement_y: integer;

Vertical movement reported by the input source. Units and interpretation follow |movement_x| and |is_raw_movement_event|.

Public is_raw_movement_event: integer;

Set to 1 when |movement_x| and |movement_y| contain raw, unadjusted OS movement, or 0 otherwise. Raw movement is independent of the DIP positions in this structure.

Public device_id: integer;

Identifier of the physical pen device on platforms that supply one. Use -1 when unavailable. This is separate from |pointer_id|, which identifies the pointer in the event stream.

Public menu_source_type: integer;

Source of a CONTEXT_MENU event, using Chromium MenuSourceType values: 0 none, 1 mouse, 2 keyboard, 3 touch, 4 touch edit menu, 5 long press, 6 long tap, 7 touch handle, 8 stylus, 9 adjust selection, 10 adjust selection reset. Use zero for other event types.
