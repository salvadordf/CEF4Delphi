Declaration

type TCefWheelInputEvent = record

Description

Portable wheel snapshot for mouse wheels and trackpad scrolling. Positions are in DIPs. Deltas and ticks are positive for scrolling up or left, opposite to DOM WheelEvent deltas. Initialize unused fields to zero.

Description

Fields

Public size: NativeUInt;

Size of this structure. Initialize to sizeof(TCefWheelInputEvent).

Public modifiers: TCefEventFlags;

Combination of TCefEventFlags CEF_EVENTFLAG_* keyboard modifiers, lock state, held mouse buttons and event-source attributes. Specify precision and page scrolling with |delta_units|, not modifier flags.

Public timestamp: int64;

Monotonic microseconds in this process. Zero uses the dispatch time. Negative values are invalid. This is not a wall-clock timestamp.

Public x: single;

Horizontal position in DIPs relative to the left edge of the browser view.

Public y: single;

Vertical position in DIPs relative to the top edge of the browser view.

Public screen_x: single;

Horizontal screen position in DIPs relative to the desktop origin.

Public screen_y: single;

Vertical screen position in DIPs relative to the desktop origin.

Public delta_x: single;

Horizontal scroll amount in |delta_units|. Preserve fractional values for high-resolution wheels and trackpads.

Public delta_y: single;

Vertical scroll amount in |delta_units|.

Public wheel_ticks_x: single;

Horizontal wheel rotation in ticks, independent of |delta_x|. A typical wheel detent is one tick. Trackpads may report fractional ticks.

Public wheel_ticks_y: single;

Vertical wheel rotation in ticks, independent of |delta_y|.

Public delta_units: TCefGestureScrollUnits;

Scroll units, sharing the gesture granularity constants. Only CEF_GESTURE_SCROLL_PRECISE_PIXEL, CEF_GESTURE_SCROLL_PIXEL and CEF_GESTURE_SCROLL_PAGE are supported. Zero selects precise pixels.

Public phase: TCefWheelEventPhase;

Phase of direct scrolling. Use CEF_WHEEL_PHASE_NONE for a discrete mouse wheel or when phase information is unavailable. BLOCKED is not valid.

Public momentum_phase: TCefWheelEventPhase;

Phase of inertial scrolling after contact ends. BLOCKED indicates that momentum will not follow. Use NONE when unavailable. Send coherent begin/update/end transitions when providing phase information.

Public rails_mode: integer;

Axis constraint: 0 for free scrolling, 1 for horizontal, 2 for vertical.

Public acceleration_ratio_x: single;

Horizontal acceleration ratio applied by the input source. Positive values are preserved; zero means unspecified and uses a ratio of one.

Public acceleration_ratio_y: single;

Vertical acceleration ratio. Same semantics as |acceleration_ratio_x|.
