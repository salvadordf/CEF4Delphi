Public function OnPreKeyboardEvent(const browser: ICefBrowser; const event: PCefKeyboardInputEvent; const context: PCefInputEventContext; out isKeyboardShortcut: Boolean): Boolean;

Called before keyboard input is offered to the renderer. Return true (1) to consume the event. To structureify it as an application shortcut for OnKeyboardEvent, set |isKeyboardShortcut| to true (1) and return false (0). Otherwise, return false (0) to try ICefKeyboardHandler.OnPreKeyEvent (if provided) before continuing normal processing. |isKeyboardShortcut| is initially false (0).

Returning true (1) for RAWKEYDOWN causes Chromium to suppress subsequent CHAR and KEYUP events until the next keydown. Suppressed events do not reach these callbacks, except that Escape KEYUP is still offered to OnPreKeyboardEvent.

Public function OnKeyboardEvent(const browser: ICefBrowser; const event: PCefKeyboardInputEvent; const context: PCefInputEventContext): Boolean;

Called for keyboard events left unhandled by the renderer. Return true (1) to consume the event or false (0) to try ICefKeyboardHandler.OnKeyEvent (if provided) before allowing normal platform fallback.

This is not an observer for every submitted event. Renderer-consumed editing commands and events marked internally to skip unhandled processing do not reach this callback. Do not assume a complete down/character/up callback sequence.

Public function OnPreMouseEvent(const browser: ICefBrowser; const event: PCefMouseInputEvent): Boolean;

Called before a mouse event is offered to the renderer. Return true (1) to consume the event or false (0) to continue normal processing. Wheel events are not delivered here. The snapshot uses the receiving widget's DIPs; it may differ from injected coordinates after frame or popup routing. No native event handle is available. If consuming a down event, also consume its corresponding up event to preserve a coherent event stream. Keep handling simple and defer complex work to avoid re-entrancy.

Public function OnPreGestureEvent(const browser: ICefBrowser; const event: PCefGestureInputEvent): Boolean;

Called before a gesture event is offered to the renderer. Return true (1) to consume the event or false (0) to continue normal processing. This is a handling opportunity, not notification of every submitted gesture. Chromium may filter gestures before this callback. No native event handle is available. Preserve coherent gesture sequences when consuming events and defer complex work to avoid re-entrancy.
