type TCefTouchEvent = record

Description

Portable event for one contact in a touch sequence. Positions and contact radii are in DIPs. Initialize unused fields to zero. Use with ICefBrowserHost.SendTouchEvent for raw touch delivery and Chromium gesture recognition.

Description

Fields

Public id: integer;

Identifier of this contact. Must remain unchanged from PRESSED through RELEASED or CANCELLED and be unique among active contacts in this browser. Any value except -1 is allowed. May be reused after the contact ends. Chromium may map this to a different DOM touch identifier. At most 16 concurrent contacts are tracked; additional contacts are ignored.

Public x: single;

Horizontal position in DIPs relative to the left edge of the browser view. Preserve fractional values when converting native coordinates.

Public y: single;

Vertical position in DIPs relative to the top edge of the browser view.

Public radius_x: single;

Horizontal radius of the contact ellipse in DIPs, before applying |rotation_angle|. Must be non-negative. Set both radii to zero when contact geometry is unavailable; Chromium then uses a default contact size.

Public radius_y: single;

Vertical radius of the contact ellipse in DIPs, before applying |rotation_angle|. Same constraints and default behavior as |radius_x|.

Public rotation_angle: single;

Clockwise rotation of the contact ellipse in degrees, in the range [0, 180

. Set to zero if rotation is unavailable. Chromium may swap the radii and normalize the angle when producing DOM touch events. )

Public pressure: single;

Normalized contact pressure in the range [0, 1]. Zero represents no pressure and should also be used when pressure is unavailable.

Public type_: TCefTouchEeventType;

State of this contact. Send one CEF_TET_PRESSED event, followed by zero or more CEF_TET_MOVED events, then one CEF_TET_RELEASED or CEF_TET_CANCELLED event. Duplicate presses and updates for inactive IDs are ignored. Moves with unchanged positions are ignored even if other contact data changes.

Public modifiers: TCefEventFlags;

Combination of TCefEventFlags values describing keyboard modifiers when this event occurred.

Public pointer_type: TCefPointerType;

Contact tool type. Use CEF_POINTER_TYPE_TOUCH for a finger, CEF_POINTER_TYPE_PEN or CEF_POINTER_TYPE_ERASER for a stylus, and CEF_POINTER_TYPE_UNKNOWN when unavailable. Zero selects a finger.
